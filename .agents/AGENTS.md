# Antigravity Unity Development Rules — [IDLE CITY] (Milestone 2 Project-Scoped Rules)

> 본 문서는 프로젝트 전용 2차 빌드 스코프 락 규약입니다. 워크플로우/명명 규칙/기본 UI 아키텍처 규칙은 상위 글로벌 룰(user_global)을 상속합니다.

---

## 🔒 2차 빌드 스코프 락 (Milestone 2 Scope Lock)

현재 프로젝트는 **2차 빌드 코어 루프 및 컨텐츠 검증 단계**입니다. 에이전트는 아래 명시된 기능 외의 코드를 선제적으로 작성하거나 클래스 구조를 설계해서는 안 됩니다.

### [A. 2차 빌드 허용 구현 범위 (UI & Data)]

1. **신규 인프라 건설 UI & 툴팁/미리보기 피드백**:
   - 고속도로(`Highway`), 일방통행(`Oneway`), 우선도로(`PriorityRoad`), 입체교차(`Overpass`), 회전교차로(`Roundabout`) 타일을 `BuildPanelController` 카테고리 탭에 정식 슬롯으로 연동하라.
   - 마우스 호버 시 설치 가능(초록)/불가(빨강) 고스트 피드백 및 혜택 범위(학교/병원 미리보기) 타일 하이라이트를 연동하라.

2. **신호등 조작 UI & 시각화 게이지 (교차로 피킹)**:
   - 교차로 타일 클릭 시 가로/세로 초록불 제로섬 배분 조절 및 시작 오프셋(±) 조절 팝업 패널을 연동하라.
   - 초록-노랑-빨강 신호 주기 막대/원형 게이지 및 실시간 커서 이동 연출을 구현하라.
   - 교차로 방향별 대기 차량 수 실시간 숫자/막대그래프 표시를 연동하라.

3. **시민 소통 (SNS 피드 & 퀘스트 UI)**:
   - 시뮬레이션 이벤트(정체 `#출근지옥`, 지각, 개교, 그린웨이브 등) 기반 시민 SNS 글 피드 UI를 구현하라.
   - 불평 글 ➔ 의뢰 수락 ➔ 달성 판정 ➔ 보상 및 감사 글 흐름의 퀘스트 UI를 연동하라.

4. **인구·채용 게이지 & 스토리 건물 정보 UI**:
   - 상단 HUD 총인구 및 다음 단계(해금) 진행 바, 회사별 채용 진행(예: 4/8명) 현황을 렌더링하라.
   - 건물 클릭 시 정량적 숫자 대신 재미있는 이야기 텍스트(예: "이 회사 직원 32명 중 11명 지각")를 바인딩하라.

5. **그린웨이브 보너스 연출 및 세이브/로드 UI**:
   - 도로 축 그린웨이브 달성 배지 및 보너스 코인 플로팅 연출을 연동하라.
   - `AutoSaveService` 저장 상태 표시 인디케이터 및 세이브/로드 슬롯 선택 UI를 연동하라.

### [B. 🚫 절대 구현 금지 대상 (3차/최종 스펙 전)]

사용자의 프롬프트에 포함되어 있더라도 아래 항목은 "2차 빌드 스코프 제외 대상"임을 경고하고 거절해야 합니다.
- **오디오 및 미디어 시스템 금지**: AudioMixer Master Filter 연동, 외부 오디오 스트리밍 및 WebView 연동 본 레포지토리 구현 금지
- **신호 자동화 구매 시스템 금지**: 후반 신호 자동화 업그레이드 선제 구현 금지 (3차 스펙 전)
- **외부 SNS 웹 연동 금지**: 실제 외부 SNS API 통신 구현 금지 (인게임 가상 피드만 허용)
