# 주석님께 — CarMotion 수정 요청 2건 (환, 2026-07-21)

소유권 계약(`2026-07-21-parallel-work-ownership.md`)에 따라 `CarMotion.cs`는 주석 전담이라
직접 고치지 않고 요청으로 넘깁니다. 근거 계측은 전부 환 쪽에서 마쳤고, 아래에 요약합니다.

## 증상 (환 라이브, hwan 씬)

1. 교차로에서 차가 겹친다 (충돌처럼 보임)
2. 앞에 차가 없는데 브레이크를 밟는다

## 원인 — 계측으로 확정 (상세: 환 로컬 계획서 §4.10~4.12, 요청 시 공유)

**인과 사슬이 파일 3개를 건너뜁니다** (소유권 문서 "신호 → 충돌" 경로 그 사슬입니다):

```text
신호 진입 게이트(RoadQueueNetwork, 2026-07-21 반영)
  → Sim은 적색 차를 정지선(접근 타일)에 정확히 세움   ← 여기까지 정상 (계측 확인)
  → CarMotion 코리도 상한 = Target + 1타일이 홀드 중에도 유효
  → 화면은 그 차를 최대 1타일 앞, 교차로 한복판에 그림  ← 여기서 무너짐
```

적색 대기 차량 1,659샘플의 화면 위치: **정지선 19.2% / 적색 교차로 위 25.8% / 코너 경로상 55.0%**,
정지선 초과 전진 avg 0.60타일·max 1.00(=코리도 한계). 그 옆을 초록 방향 차가 지나가면
충돌·추월로 보입니다. 유령 브레이크 쪽은 감속 이벤트의 58.9%가 앞차 연쇄 전파,
35.8%가 Sim 홀드의 번역입니다(뷰 결함 아님 — 다만 아래 2번이 착시를 증폭).

## 요청 1 — 홀드 시 코리도 붕괴

`TargetAdvancing == false`(Sim이 잡고 있음)면 코리도 상한을 `Target + 1타일`이 아니라
**`Target`(정지선)으로**. +1타일 여유는 흐르는 교통을 위한 것이니 흐를 때만.

- 기대 효과: 적색 차가 정지선 앞에 선다 → "이유 없는 멈춤"이 "빨간불 정차"로 읽히고,
  교차로 위 겹침 착시가 사라진다.
- 데드락 무관: 정지 사유는 불변, 정지 위치만 정확해진다.

## 요청 2 — lag 밴드 축소

차량별 지연이 −0.57 ~ +2.22타일(편차 2.79 = 차간거리 0.55의 5배)로 퍼져, 다른 차선 차와의
화면 순서 역전이 15% 발생 → 추월 착시. **홀드에서 풀린 차의 따라잡기 회복을 빠르게**
(정지 누적분 즉시 회복) 편차를 좁혀 주세요. 같은 차선 안 역전은 1.1%로 문제없음 — 손댈 필요 없음.

## 검증 게이트 (수정 후 환이 재계측)

- 적색 대기 차량의 화면 위치: 정지선 비율 19% → 대폭 상승, 교차로 위 25.8% → ~0
- 급정지 한계 초과 0 유지 · 워치독(60초) 0 유지 · 지연 발산 없음
- 겹침/1k차프레임: 18.8(현재)에서 감소

## 이 요청의 범위 밖 (참고)

- Sim 홀드 자체를 줄이는 것(교차로 중재 라운드 증가)은 **환 몫** — 위 2건 반영 후 재계측하고 진행.
- 노랑 없이 뚝 서는 신호 연출(3상 배선)은 **준희 몫** — 별도 논의.
