# 연구 트리(틀) 인계 브리프 — 진우 님

2026-07-31, 환. 연구 해금을 **자동 → 조건 충족 + 유저 클릭**으로 바꾸고, 패널을
좌→우 전제 사슬 트리로 개조한 **골격**입니다. 밸런스·비주얼·확장은 진우 님 관할로 넘깁니다.

## 동작 방식

- 조건(어제 도착·인구·시설 수)을 채우고 **전제 연구가 해금돼 있으면** 노드가 "해금 가능"이 되고,
  클릭하면 해금됩니다 (`IsReady` → `TryUnlock`). 자동 해금은 더 이상 없습니다
- 세이브는 종전 해금 집합 그대로 — 기존 세이브에서 이미 열린 연구는 그대로 인정됩니다
- 패널: 전제 깊이 = 열(왼→오), 갈래 = 행. 연결선은 전제 해금 여부로 회색/초록

## 진우 님이 코드 없이 만질 수 있는 것

**`Assets/05_ScriptableObjects/Resources/CityFlow/ResearchCatalog.asset`** — 트리의 단일 출처:

| 필드 | 의미 |
|---|---|
| `prerequisiteId` | 전제 연구 id. 비우면 루트(갈래 시작). **사슬 재구성은 이 필드만 바꾸면 됨** |
| `conditionKind` | 0=어제 도착 · 1=인구 · 2=시설 수(`targetTileType`) |
| `threshold` | 조건 임계값 |
| `displayName` | 노드 표시명 |

현재 사슬: 상업 커피숍→비디오→영화관 / 교통 주유소→정비소→몰 / 공공 약국→경찰서.
노드 추가 시 entries에 항목만 추가하면 레이아웃이 자동으로 따라갑니다(열·행·연결선 전부 코드 계산).

UI 셀 크기·간격: `ResearchPanelController.cs` 상단 상수(CellWidth/CellHeight/ColumnGap/RowGap).

## 남은 결정 (진우 님 몫)

1. **임계값 페이싱** — 인구 80·통행 150은 하루 720초 시절 수치. 지금 하루 180초 기준으로
   데모 15분 안에 도달 가능한지 재조정 권장
2. **갈래 배타 선택** 여부 — 지금은 순서 자유(모두 해금 가능). 한쪽 고르면 반대쪽이 잠기는
   전략성을 원하면 로직 추가 필요(요청 주시면 처리)
3. 비주얼 폴리시(노드 아이콘·해금 연출 등)
