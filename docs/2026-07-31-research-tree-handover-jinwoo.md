# 연구 트리(틀) 인계 브리프 — 진우 님

2026-07-31, 환. 연구 해금을 **자동 → 조건 충족 + 유저 클릭**으로 바꾸고, 패널을
좌→우 전제 사슬 트리로 개조한 **골격**입니다. 밸런스·비주얼·확장은 진우 님 관할로 넘깁니다.

## 동작 방식

- 조건(어제 도착·인구·시설 수)을 채우고 **전제 연구가 해금돼 있으면** 노드가 "해금 가능"이 되고,
  클릭하면 해금됩니다 (`IsReady` → `TryUnlock`). 자동 해금은 더 이상 없습니다
- 세이브는 종전 해금 집합 그대로 — 기존 세이브에서 이미 열린 연구는 그대로 인정됩니다
- 패널: 전제 깊이 = 열(왼→오), 갈래 = 행. 연결선은 전제 해금 여부로 회색/초록

## 진우 님이 코드 없이 만질 수 있는 것

**`Assets/05_ScriptableObjects/Resources/CityFlow/ResearchCatalog.asset`** — 트리의 단일 출처:

밸런스 수치 조정은 `CityFlow > Balance > 밸런스 편집기 열기`의
`연구 > 건물 해금 연구`에서 진행합니다. 편집기는
`Assets/05_ScriptableObjects/Balance/Editor/ResearchCatalog_Balance.asset`을
작업용 복사본으로 사용하며, 작업 공간을 열면 연구 서비스와 연구 UI가 이
복사본을 자동 참조합니다. 검증 후 `확정값 실제 에셋에 반영`을 눌러야 실제
게임 카탈로그가 갱신됩니다.

연구 편집 화면은 연구 선택 → 이름과 선행 연구 → 해금 조건 → 비용과 시간
순서로 구성됩니다. 선행 연구와 조건 종류는 직접 ID를 입력하지 않고 선택
목록으로 지정할 수 있으며, 연구 ID는 고급 설정에 숨겨져 있습니다.

현재 실제 해금 건물은 총 10개입니다.

- 학교: 500 / 24시간
- 병원: 750 / 36시간
- 커피숍: 100 / 12시간
- 비디오 대여점: 150 / 18시간
- 약국: 200 / 18시간
- 주유소: 250 / 24시간
- 차량 수리점: 350 / 30시간
- 영화관: 450 / 36시간
- 경찰서: 600 / 48시간
- 큰 상점: 800 / 72시간

약국은 학교 연구 완료 후 진행할 수 있습니다. 비디오 대여점·영화관,
주유소·차량 수리점·큰 상점은 각각 기존 선행 연구 사슬을 유지합니다.
이 값들은 초기 밸런스이며 연구 밸런스 편집기에서 조정합니다.

| 필드 | 의미 |
|---|---|
| `prerequisiteId` | 전제 연구 id. 비우면 루트(갈래 시작). **사슬 재구성은 이 필드만 바꾸면 됨** |
| `conditionKind` | 0=어제 도착 · 1=인구 · 2=시설 수(`targetTileType`) |
| `threshold` | 조건 임계값 |
| `displayName` | 노드 표시명 |
| `researchCost` | 연구 시작 시 즉시 차감되는 코인 |
| `researchDurationHours` | 완료까지 필요한 게임 시간 |
| `requirements` | 여러 조건을 모두 만족해야 할 때 사용하는 조건 목록 |

현재 사슬: 상업 커피숍→비디오→영화관 / 교통 주유소→정비소→몰 / 공공 약국→경찰서.
노드 추가 시 entries에 항목만 추가하면 레이아웃이 자동으로 따라갑니다(열·행·연결선 전부 코드 계산).

학교·병원은 기본 타일 건물이지만 연구 완료 전에는 건설 슬롯과 실제 배치 양쪽에서 잠깁니다.
기본값은 학교 `주거 3 + 회사 2 / 500코인 / 24게임시간`, 병원
`주거 5 + 회사 3 / 750코인 / 36게임시간`입니다. 한 번에 하나의 연구만 진행되며,
진행 중 연구와 완료 예정 게임 시간은 저장·복원됩니다.

UI 셀 크기·간격: `ResearchPanelController.cs` 상단 상수(CellWidth/CellHeight/ColumnGap/RowGap).

## 남은 결정 (진우 님 몫)

1. **임계값 페이싱** — 인구 80·통행 150은 하루 720초 시절 수치. 지금 하루 180초 기준으로
   데모 15분 안에 도달 가능한지 재조정 권장
2. **갈래 배타 선택** 여부 — 지금은 순서 자유(모두 해금 가능). 한쪽 고르면 반대쪽이 잠기는
   전략성을 원하면 로직 추가 필요(요청 주시면 처리)
3. 비주얼 폴리시(노드 아이콘·해금 연출 등)
