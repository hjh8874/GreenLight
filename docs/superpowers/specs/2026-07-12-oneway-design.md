# 설계 — 일방통행 (방향 도구 1단계, 티어2 1순위)

> 작성: 2026-07-12 (환 자율 위임 — /goal "다음 우선순위 작업 진행", plan-next-dev §B-1 이행). 짝 계획: 2026-07-12-oneway.md.
> 선행 스택: SimConfig seam(`feat-simconfig-seam-hwan`, 163) 위. 브랜치 `feat-oneway-hwan`.
> 배경: 유저가 골목을 일방통행으로 지정 → 역방향 차들이 강제로 우회로를 탄다 — 순환선(Loop) 조각 퍼즐. 턴 제한(2단계)의 방향 라우팅 기반을 이 단계에서 상태 확장 없이 깐다.

## 목표 / 스코프

**도로 타일에 통행 방향 1개(E/W/N/S)를 배치하는 구매템.** 라우팅이 그 방향만 허용 — 흐름 수식·용량은 무변경(순수 라우팅 도구). 엔진(배치+라우팅 필터+세이브) + 뷰(화살표 마커+역주행 유령 숨김) + 샌드박스 키. 가격·상점 UI는 팀 몫.

## 핵심 결정 (근거 포함)

| 결정 | 내용 | 근거 |
|---|---|---|
| **교차로 금지 — 일반 도로 전용** | 배치 조건 = 도로 && `!IsIntersection` | 교차로 위 일방통행은 의미 모호(그건 턴 제한의 영역). 덕분에 신호/로터리/입체(교차로 전용)와 **자연 배타** — 배타 검사 추가 불요 |
| 상태 = 좌표→방향 맵 | `Dictionary<Vector2Int, Vector2Int>`(단위 스텝) + flat 정렬 List(순회·세이브 순서) | 방향 값이 있어 "좌표-전용 셋" 공통화 대상이 아님. **공통화 리팩터는 이번에 발동 안 함** — 조건(4번째 *좌표-전용*)은 방지턱(travelSlots, 진짜 좌표-전용)이 충족할 예정. 원장 이월 판정 갱신 |
| **라우팅 = 간선 필터, 상태 확장 없음** | Search 이웃 확장에서 ①일방 타일 A에서 나가는 스텝은 D만 ②일방 타일 B로 들어가는 스텝은 −D 금지(역주행 진입 차단, 측면 합류는 허용) ③일방 타일이 관여하는 대각 스텝 금지(단순화) | 탐색 상태 (타일) 유지 = 이 단계의 핵심 절약(로드맵 결정 로그). 측면 합류 허용이 현실 부합 + 미도달 최소화 |
| 배치 모드 전용 + TopologyDirty | `!AutoDetectSignals` 게이트(구매템 통일), 배치/철거 시 재계획 강제 | 신호와 달리 **라우팅에 영향** — dirty 없으면 경로가 낡는다. MarkTopologyDirty(seam에서 신설) 재사용 |
| 도로 소멸 시 프루닝 | 철거로 도로가 아니게 되면 자동 소멸(교차로**화**돼도 소멸 — 배치 조건 위반) | 신호 가족과 동일 규약, 단 조건이 반대(비교차로 유지) |
| 세이브 = 좌표+방향 | `Oneways`(X,Y,DirX,DirY) optional 배열 — 배치물 세이브 첫 방향 필드 | 구세이브 null=0개. 복원 시 배치 조건 재검증(손상 세이브 방어 — 교차로 좌표면 버림) |
| 뷰 유령 = **숨김(해법 ①)** | 복귀(fold) 구간 차량이 일방 타일 위에서 역방향이면 렌더러 숨김 | plan-next-dev의 A/B 중 침습 최소. 경계 팝은 기존 차선 팝과 같은 급 — 수용 |
| 마커 = 방향 화살표 | 도로 위 z에 삼각 화살(프리미티브 조합), 방향 회전 | 에셋 스왑 지점 1함수 수렴(기존 규약) |
| 샌드박스 키 `4` | 호버 도로에 배치(E부터), 이미 있으면 방향 회전(E→S→W→N), `0` 철거(기존) | 손 테스트 즉시 가능 — 4형제 검증 루프와 동일 UX |

## §1. 엔진 — SimEngine 배치 API + RoutePlanner 필터

- API: `CanPlaceOneway(tile)`/`TryPlaceOneway(tile, Vector2Int dir)`/`TryRemoveOneway(tile)`/`OnewayTiles`/`GetOnewayDir(tile)`(뷰·저장용, 없으면 zero). dir은 4방 단위 벡터만(검증). ISignalControl 제안 누적(18종 도달 — **배치물 공통 계약 분리를 김건 안건으로 격상** 주석).
- RoutePlanner.Search: 이웃 확장 지점에 3규칙 필터(위 표). 엔진 소유 맵을 Plan 호출 인자로 전달(로터리 셋과 같은 패턴 — 소유·갱신은 SimEngine).
- 프루닝: RebuildSignals의 소멸 블록에 4번째(조건: `IsRoad && !IsIntersection` 유지 확인).
- SettleOffline: dirty 소비가 이미 선행(기존) — 추가 배선 없음.

## §2. 세이브

`SimSaveData.Oneways`(`OnewaySaveData[]` — X,Y,DirX,DirY). CreateSnapshot/RestoreSnapshot 배치 모드 블록, 신호·로터리·입체 뒤 4번째(손상 세이브: 배치 조건 재검증 후 채택, flat 정렬).

## §3. 뷰 — MainCityView

- `RefreshOneways()`: `OnewayTiles` 폴링, 화살표 마커(방향 = GetOnewayDir 회전). 기존 마커 수명 규약.
- MoveVehicle: 복귀 구간(`!forward`)에서 `insideTile`이 일방이고 `travelDir ≈ −D`면 `vehicle.Renderer.enabled = false`(다음 프레임 조건 해제 시 복원). AngryMark 등 부속도 함께 숨김.

## §4. 테스트 (EditMode — OnewayTests)

1. 배치 규칙: 일반 도로 OK / 교차로·비도로·중복·자동모드 거부 / dir 검증(대각·zero 거부) / 방향 회전은 철거+재배치로(재배치 API 아님 — 샌드박스가 조합)
2. **우회 라우팅**: 평행 2본 도로 기하(우회로 존재) — 일방 배치 → 역방향 수요가 우회로로 재계획, delivered 유지. 구현 전 RED 필수
3. **미도달 무사고**: 우회로 없는 외길에 역방향 일방 → 해당 수요 미배정(delivered 그 몫만 0, 예외 없음)
4. 측면 합류 허용 / 역주행 진입 금지 구분 핀
5. 도로 철거·교차로화 시 자동 소멸
6. 세이브 라운드트립(방향 보존) + 레거시(null) + 결정론
7. 회귀: 기존 163 전부 그린(일방 0개면 필터 무비용 경로)
