# 설계 — 턴 제한: 좌회전만/우회전만 (방향 도구 2단계)

> 작성: 2026-07-12 (환 자율 위임 — "3번으로 바로 가자"). 짝 계획: 2026-07-12-turn-restrict.md.
> 선행 스택: 일방통행(`feat-oneway-hwan`, 180) 위. 브랜치 `feat-turn-restrict-hwan`.
> 배경: 교차로에 배치하는 방향 배분 표지판 — "좌회전만"이면 진입 차량이 반드시 좌회전 → P턴·한 바퀴 우회가 창발("동선이 길어져도 멈추지 않는 게 이득일까?"). 환 확정 프레임: **신호=시간 배분, 표지판=방향 배분 — 같은 교차로에 공존**.

## 목표 / 스코프

교차로 타일에 표지판(LeftOnly/RightOnly) 배치. 라우팅 탐색 상태를 **(타일 × 진입방향)**으로 확장하되, **표지판 0개면 기존 탐색 경로를 그대로 타서 행동 변화 0**. 흐름 수식 무관. 엔진+세이브+뷰 마커+샌드박스 키. 가격·UI는 팀 몫.

## 핵심 결정 (근거 포함)

| 결정 | 내용 | 근거 |
|---|---|---|
| 모드 2종 enum | `TurnMode { LeftOnly, RightOnly }` — 확장 여지 있는 enum(직진만·좌회전금지는 후보) | 환 요구 그대로("좌회전만, 우회전만"). v0 최소 |
| **회전 정의** | 진입 스텝 d의 좌회전 = d를 반시계 90°(y-up 좌표: East→North), 우회전 = 시계 90°. U턴 상시 금지 | 수학 명료·결정론. 뷰 좌표계(y-up)와 일치 |
| **신호와 공존, 로터리·입체와 배타** | CanPlaceTurnSign = 교차로 && 로터리/입체 없음(신호는 무관) | 신호(시간)와 표지판(방향)은 직교 — 공존이 프레임의 핵심. 로터리/입체는 회전 의미론이 달라 중첩 금지 |
| **표지판 0개 = 레거시 탐색** | Search 진입부에서 `signs.Count == 0`이면 기존 (타일) 상태 탐색 그대로 | 상태 확장은 동률 tie-break를 바꿔 기존 경로가 미묘하게 달라질 수 있음 — 기존 180 테스트·라이브 결정론의 무풍지대 보장. 이중 경로 비용 < 회귀 위험 |
| 상태 확장 = (타일 × 4방향) | 표지판 있을 때만: dist/cameFrom을 [n×4]로, 진입방향 인덱스 고정 순회(E,S,W,N) | 20×20×4=1,600 노드 — 부담 없음. 결정론 = 고정 순회 |
| **표지판 교차로는 카디널 전용** | 표지판 타일로의/에서의 대각 스텝 금지 | 대각의 회전 판정 모호 제거(일방통행과 동일 단순화). 나머지 대각은 현행 유지 |
| **경로에 타일 중복 허용** | P턴은 같은 타일을 다른 진입방향으로 재방문할 수 있음 — 경로 재구성은 (타일,방향) 체인 | FlowSolver.AxisWeights는 스텝 단위라 중복 무해(확인 필요 항목으로 계획에 명기). 재방문 금지는 P턴 자체를 죽임 |
| 세이브 = 좌표+모드 | `TurnSigns`(X,Y,Mode int) optional — 5번째 가족 | 구세이브 null=0개. 복원 재검증(교차로 && 배타) |
| 뷰 = 굽은 화살 마커 | 좌/우 방향 굽은 화살(프리미티브 조합), 신호 마커와 같은 타일 공존 시 z 분리 | 에셋 스왑 1함수 수렴 규약 |
| 샌드박스 `5`키 | 호버 교차로에 배치(LeftOnly 시작), 재입력 시 Left→Right 회전, `0` 철거 체인에 추가 | 4형제+일방과 동일 손 테스트 UX |

## §1. 엔진 — 배치 + 라우팅

- SimEngine: `_turnSigns` Dictionary<Vector2Int, TurnMode> + flat List. API 4종+GetTurnMode(뷰·저장) — ISignalControl 제안 누적(22종 — 공통 계약 분리 안건 재강조). 배치/철거 시 MarkTopologyDirty. 프루닝 = 교차로 해제 시 소멸(신호 가족 규약).
- RoutePlanner.Plan/Search에 turnSigns 전달(null 위임 체인 연장). Search: 표지판 0개 → 기존 경로. 있으면 상태 확장 탐색 — 표지판 타일 T에 진입방향 d로 들어온 상태에서 나가는 스텝 d'는 `Turn(d→d') == 표지판 모드`만 허용(U턴 상시 금지, 대각 금지). 비용 함수·혼잡 가중은 무변경.
- 시작 타일: 진입방향 없음 — 첫 스텝이 상태를 확립(시작 타일이 표지판이면 제약 없이 출발 — 진입이 아니므로. 명시 결정).

## §2. 세이브 / §3. 뷰 / §4. 샌드박스

기존 가족 규약 그대로(§핵심결정 참조). 뷰 마커: 몸통 바 + 꺾인 촉(좌/우), GetTurnMode로 형태 선택.

## §5. 테스트 (TurnRestrictTests)

1. 배치/배타(로터리·입체 거부, **신호 공존 허용 핀**)/철거/소멸/자동모드 거부
2. **P턴 창발**: LeftOnly 교차로에서 직진 수요가 좌회전 우회 경로(같은 타일 재방문 가능)를 찾음 — RED 필수
3. U턴 금지 / 대각 금지 / 미도달 무사고(우회 불가 시 미배정)
4. **레거시 무풍**: 표지판 0개면 기존 경로와 완전 동일(대표 기하 1개에서 경로 자체 비교)
5. 세이브 라운드트립(모드 보존)+레거시+결정론. 기존 180 전부 그린

## 비목표

직진만/좌회전금지 모드(후속), 표지판별 시간제(신호 연동 심화), 대각 회전 의미론(현행 금지 유지), 가격(진우).
