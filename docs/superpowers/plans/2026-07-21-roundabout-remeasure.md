# 로터리 재측정 + 우회전 클램프 결함 수정 (2026-07-21)

소유권 문서(`docs/2026-07-21-parallel-work-ownership.md`)의 미해결 항목
"`MinTransitionSpan 0.66`이 어느 궤도 반경에서 측정된 값인지 기록이 없다 — 재측정하라"의 이행.
베이크 수학을 그대로 재현(스크립트)해 4개 이동 전부 섬 최소 이격을 다시 쟀다.

## 측정 조건 (이번엔 기록한다)

- R(`roundaboutOrbitRadius`) = 0.775, α = 45°, span(`roundaboutTransitionTiles`) = 0.66, λ(`laneOffset`) = **0.26**
- 방법: `ApplyRoundaboutGeometry`의 전이 베지어(QuarterCircleHandle 0.5523) + 원호 + 링 생략 경로를
  수치 재현, 200 샘플로 중심 최소 거리 측정. 섬 하한 `IslandClearance` = 0.62.

## 측정 결과

| 이동 | 경로 | 중심 최소 거리 | 판정 |
|---|---|---|---|
| 직진 (sweep 90°) | 전이+원호 | 0.654 | 통과 (+0.034) |
| 좌회전 (sweep 180°) | 전이+원호 | 0.654 | 통과 (+0.034) |
| U턴 (sweep 270°) | 전이+원호 | 0.654 | 통과 (+0.034) |
| **우회전 (링 생략)** | 코너 베지어 | **0.485** | **클램프 상시 작동 (−0.135)** |

- `MinTransitionSpan 0.66` 하한 자체는 R=0.775에서도 유효 — R을 0.68~0.9로 흔들어도 0.639~0.657로 전부 통과.
- **우회전은 R과 무관**(링 생략 경로는 span·λ만의 함수)이라 반경 통일 전부터 항상 클램프에 의존해 왔다.

## 발견한 결함

1. **우회전 경로가 클램프로 성형된다.** "클램프는 보험(평시 무동작)"(RoutePolyline.cs:437-438) 주장과 달리
   우회전에선 상시 작동. 경로 모양이 의도한 베지어가 아니라 반경 클램프의 부산물이다.
2. **`ClampIslandIntrusion`이 `Pos`만 밀고 `Dir`을 안 고친다**(RoutePolyline.cs:445-462).
   클램프된 구간에서 차 헤딩(베지어 접선)과 실제 경로(0.62 원호)가 어긋나 옆으로 미끄러지는 연출.
   `CarMotion`(주석 소유)이 이 `Dir`을 읽으므로 경계 계약 접점.
3. **주석(코멘트) 3중 부패**: λ=0.18이라 쓰여 있으나 실제 0.26(MainCityView.cs:46) /
   "실측 R=0.9" 전제이나 현재 0.775 / "RoutePolyline.cs:316,392" 참조는 현재 437·443.
   R=0.9·λ=0.18로 재현해도 "실측 최저 0.68"은 안 나온다(0.615) — 측정 조건 미기록의 대가.

## 수정 계획 (전부 환 소유 파일)

1. **Dir 재계산** — `ClampIslandIntrusion`에서 클램프가 한 번이라도 작동했으면, 클램프된 정점의
   `Dir`을 인접 정점 현(chord) 방향으로 재계산. `RoutePolyline.cs`만 수정, 위상 배정 전이므로 순서 안전.
2. **주석 갱신** — `MinTransitionSpan`·`IslandClearance` 주석에 이번 측정 조건(위 표)을 명기,
   λ=0.26 반영, 죽은 라인 참조 제거. `MainCityView.cs:79`의 로터리 노브 주석도 동일 정정
   (환 구역의 기존 필드 주석 수정 — SerializeField 추가 아님, 금지 조항 위반 없음).
3. **회귀 테스트** — `RoutePolylineTests.cs`에 우회전 케이스 추가: ①전 정점 중심 거리 ≥ 0.62
   ②각 정점 `Dir`과 다음 정점으로의 현 방향 각차 상한.
4. **(보류) 우회전 기하 자체 재설계** — 클램프 비의존 경로(진입→섬 가장자리 호→이탈).
   1번으로 헤딩 어긋남이 사라진 뒤 자기 씬(`Debug/CityFlowIntegrated_hwan.unity`)에서 육안 확인,
   여전히 꺾여 보일 때만 착수. // ponytail: 클램프 성형 유지, 육안 불합격 시 호 삽입으로 승격

준수 사항: 씬 커밋 없음(자기 씬에서만 확인) / SerializeField 추가 없음 / SimConfig 무관 /
`Dir` 의미 변화는 폴리라인 형상 계약이므로 **머지 전 주석에게 공유**.
