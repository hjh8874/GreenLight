**Goal:** 도로 타일 두 곳에 램프를 놓으면 그 사이가 고가로 직결되는 고속도로 — Sim 링크 큐 + 라우팅 간선 + 배치/세이브 + 폴리라인 고가 세그먼트.

**Architecture:** 링크 = RoadQueueNetwork 안의 FIFO 지연 큐(로터리 링 셀 패턴). 라우팅 = RoutePlanner 다익스트라에 램프 간선 추가. 배치 = SimEngine 로터리 배치 패턴(`MarkTopologyDirty` → 다음 틱 전체 리빌드, 뷰는 폴링). 뷰 = RoutePolyline 고가 세그먼트(경계 계약 → 주석 통지).

**Tech Stack:** Unity 6000.5.2f1 · C# · NUnit EditMode · 기존 CityFlow Sim/ViewKit.

```csharp
// RoadQueueNetwork 내부
private struct HighwayLinkState {
    public int RampA, RampB;          // TileIndex
    public int TransitTicks;          // ceil(맨해튼거리 / HighwaySpeedFactor)
    public int Capacity;              // 맨해튼거리 × HighwayDensityPerTile
}
private HighwayLinkState[] _highwayLinks;                 // RebuildTopology에서 재구성
private readonly Dictionary<int, int> _rampToLink = new(); // rampTileIndex → linkIndex
// 방향별 탑승자: linkIndex*2 + (0=A→B, 1=B→A). (node, exitTick) FIFO — List로 충분(링크당 소수)
private List<(int node, int exitTick)>[] _linkCars;
private int _tickCounter;   // Step 호출마다 ++ (exitTick 기준. signalGate tick과 별개로 자체 카운터)
```

- `RebuildTopology`: 도로 순회 중 `device.TryGetHighwayPartner(tile, out p)`면 링크 등록(중복 방지: TileIndex(a) < TileIndex(p)일 때만 생성). 링크 위 차량은 리빌드 시 **가장 가까운 램프 큐로 강제 복귀**(로터리 리빌드와 동일한 "장치 소멸 시 차 보존" 규약 — 기존 로터리 처리 방식을 `RebuildTopology`에서 확인 후 동일하게).
- `CollectIntents`: 헤드의 `next`가 현재 타일의 램프 파트너면(비인접!) `IntentKind.HighwayEntry` 인텐트. 게이트 = 해당 방향 `_linkCars` count < Capacity. 만석이면 `_blockedTicks[node]++`.
- `ExecuteIntent` HighwayEntry: `DetachHead` → `_linkCars[dir].Add((node, _tickCounter + TransitTicks))` → `_movedThisTick[node]=true`, `_blockedTicks[node]=0`.
- `ServiceHighwayLinks`: 각 링크·방향의 head(`[0]`)가 `exitTick <= _tickCounter`면 진출 시도 — 진출 큐 = `(rampB, EntryDirFromLink)`, `CanAcceptNormally` 실패 시 대기(`_blockedTicks[node]++`, **Force 없음** — 출구는 일반 그리드 밸브가 보장). 성공 시 `AttachHead`/기존 인큐 경로 재사용, FIFO pop.
  - `EntryDirFromLink` = 링크 벡터(a→b)의 지배축 방향의 `Opposite` (예: 동쪽으로 뻗은 링크로 도착 → 서쪽에서 진입한 것).
- `TryLocateCar` 확장: 큐 → 링 셀 → **링크 순회**. 링크 위 차: `tile = 출발 램프`, `slot=0`, `linkProgress01 = 1 - (exitTick - _tickCounter) / (float)TransitTicks` (clamp01).
